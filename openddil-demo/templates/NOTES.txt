{{- if include "openddil.linkControlEnabled" . }}
DDIL sever (toxiproxy):
  One link per uplink: each child tier's uplink to its parent is its own
  toxiproxy proxy, uplink-<child id>. A tier's screen toggles its own
  uplink (/proxies/uplink) and each direct child's (/proxies/<child id>),
  so the same link is cut from either end. HQ has no uplink. The same
  route sets a link's latency, jitter and bandwidth; a slow link stays up.
  Disabling a proxy severs the link for real, not simulated.
